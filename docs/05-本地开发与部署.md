# 05 · 本地开发与部署

---

## 环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| Node.js | **≥ 18**（推荐 20 / 22 LTS） | Vite 6 的最低要求是 Node 18 |
| 包管理器 | npm（也可用 pnpm / yarn） | 仓库内只有 `package-lock` 之外无锁文件约束 |
| 浏览器 | 任一现代浏览器 | 导出打印依赖 `@media print` 与 `print-color-adjust` |

本项目是**纯前端应用**，不需要数据库、不需要后端服务、不需要模型密钥。

---

## 安装与运行

```bash
npm install
npm run dev
```

`dev` 脚本固定监听 **3000** 端口并开放 `0.0.0.0`（方便局域网 / 手机实测）：

```json
"dev": "vite --port=3000 --host=0.0.0.0"
```

访问 http://localhost:3000

---

## 全部脚本

| 脚本 | 命令 | 用途 |
|---|---|---|
| `dev` | `vite --port=3000 --host=0.0.0.0` | 开发服务器 |
| `build` | `vite build` | 生产构建 → `dist/` |
| `preview` | `vite preview` | 预览构建产物 |
| `lint` | `tsc --noEmit` | **类型检查**（本项目唯一自动化校验） |
| `clean` | `rm -rf dist server.js` | 清理产物 |

> ⚠️ `clean` 里的 `server.js` 是 AI Studio 模板遗留，仓库中并不存在该文件。在 Windows 上 `rm -rf` 也不适用——如需跨平台请改用 `rimraf`。

## 环境变量

复制模板：

```bash
cp .env.example .env
```

| 变量 | 说明 | 当前是否需要 |
|---|---|---|
| `GEMINI_API_KEY` | Gemini API 密钥。AI Studio 运行时会从用户 Secrets 自动注入 | **不需要**——当前版本所有内容均为静态数据 + 本地确定性计算，**没有任何模型调用** |
| `APP_URL` | 应用自身 URL（自引用链接、OAuth 回调） | 可选，本地静态预览用不到 |

> `metadata.json` 声明了 `MAJOR_CAPABILITY_SERVER_SIDE_GEMINI_API`，但当前源码中 **没有任何 `@google/genai` 的引用**。若后续引入模型调用（如自动生成章节摘要），此能力声明才会真正生效。

## 构建

```bash
npm run build     # → dist/
npm run preview   # 本地验证产物
```

产物是**纯静态站点**（HTML + JS + CSS），可部署到任何静态托管：

| 平台 | 方式 |
|---|---|
| Cloudflare Pages | 构建命令 `npm run build`，输出目录 `dist` |
| Vercel / Netlify | 同上，框架预设选 Vite |
| GitHub Pages | `dist` 推到 `gh-pages` 分支；注意 Vite 的 `base` 需按仓库路径调整 |
| 内网 Nginx | `dist` 直接丢根目录 |
| 完全离线 | 不走构建——直接在应用里导出「离线单文件 HTML」，双击即用 |

> **不需要服务端**，因此不存在 SSR / API 路由 / 冷启动之类问题。

## AI Studio 工作流相关

本项目的 `vite.config.ts` 里有一段 AI Studio 专用逻辑：

```ts
server: {
  // HMR is disabled in AI Studio via DISABLE_HMR env var.
  // Do not modify—file watching is disabled to prevent flickering during agent edits.
  hmr: process.env.DISABLE_HMR !== 'true',
  watch: process.env.DISABLE_HMR === 'true' ? null : {},
}
```

**含义**：AI Studio 内编辑代码时会把 `DISABLE_HMR` 置为 `true`，关闭热更新与文件监听，避免编辑器不断触发重建造成闪烁。

- 本地开发：**不要**设置 `DISABLE_HMR`，保持 HMR 开启
- 在 AI Studio 里调试异常时：确认该变量是否被置位

### 从 AI Studio 导出代码

AI Studio 右上角菜单 → **Export** → **Download ZIP** 可拿到完整工程；也可直接 **Push to GitHub**。

## 开发注意事项

| 事项 | 说明 |
|---|---|
| **改动前先跑 `npm run lint`** | 项目无测试，`tsc --noEmit` 是唯一的静态保障 |
| **打印相关改动必须在真实浏览器验证** | 分页效果无法通过类型检查发现，且不同浏览器 `@media print` 实现有细微差异 |
| **导出器与正文存在内容重复** | 改正文文案时请同步 `utils/htmlExporter.ts` 与 `utils/markdownExporter.ts`（详见 [03-导出链路与打印适配.md](03-导出链路与打印适配.md)） |
| **不要依赖 `npm run clean`** | 见上文模板遗留说明 |
| **字体来自 Google Fonts CDN** | `index.html` 引入了 Cormorant Garamond / Inter / Space Mono / JetBrains Mono / Noto Sans SC / Noto Serif SC。内网离线环境会回退到系统字体，版式略有差异 |
